# Memory Game

Браузерная игра на запоминание: на поле лежат 16 карточек рубашкой вверх, под ними спрятаны 8 пар картинок. Нужно найти все пары за как можно меньшее число ходов.

## Как играть

1. Нажмите на любую карточку, затем на вторую. Это один ход.
2. Если картинки совпали, пара остаётся открытой.
3. Если не совпали, обе карточки закроются примерно через секунду. В это время другие карточки открыть нельзя.
4. Когда найдены все 8 пар, появится окно с итоговым числом ходов.

Кнопка «Новая игра» в любой момент перемешивает карточки и обнуляет счётчики. Кнопка «Таблица лидеров» показывает 10 лучших результатов: чем меньше ходов, тем выше место. Результаты хранятся в `localStorage` браузера и не пропадают после перезагрузки страницы.

## Локальный запуск

Нужен Node.js актуальной LTS-версии.

```bash
git clone https://github.com/SlavaPankov/memory-game.git
cd memory-game
git checkout memory-game
npm install
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминале (по умолчанию `http://localhost:5173`).

Сборка и просмотр готовой версии:

```bash
npm run build
npm run preview
```

Собранные файлы лежат в папке `dist`.
